# 인사이트 프로토콜 (대회 세션용, 짧게 유지)

인사이트는 **규칙이 아니라 검증 이력이 붙은 가설**이다. 조건이 맞을 때만 쓰고, 써도 CV로 판정한다.

## 읽기 (실행 시작 시, 지시 확인 단계에서)
1. `insights/common.md` 와 이 대회 유형의 `insights/playbooks/<type>.md` 만 읽는다. `inbox/`는 읽지 않는다.
2. 각 항목의 **조건**이 이 대회와 맞는 것만 고려한다. 조건이 안 맞으면 무시한다.
3. 쓸 만한 항목은 바로 적용하지 말고 `HYPOTHESES.md`에 `(근거: I-xx)`를 달아 가설로 등록한 뒤, 그 가설의 채택/기각 기준으로 CV 판정한다.
   - 예외: 운영·인프라 항목(예: 대기열, 제출 형식)처럼 CV로 판정할 대상이 없으면 그대로 따르고 결과만 기록한다.

## 쓰기 (실행 끝, 리포트 단계에서. 해당 사항이 있을 때만)
`insights/inbox/<slug>.md` 맨 아래에 한 줄씩 추가한다. 다른 파일은 고치지 않는다 (`common.md`·playbook 수정은 큐레이터만).

```
- YYYY-MM-DD | used I-xx | 결과: CV +0.004 (exp031) / 반례: CV −0.01, 조건 X가 달랐음
- YYYY-MM-DD | new | 조건: ... | 행동: ... | 근거: <exp id, CV/LB 변화> 
```
- `used`: 인사이트를 실제로 근거로 삼았을 때만. 읽기만 한 것은 쓰지 않는다.
- `new`: **다른 대회에도 통할 만하고**, 모델이 기본으로는 안 했을 행동이고, 수치 근거가 있을 때만. 이 대회에만 해당하는 지식은 대회 폴더에 둔다.
- 쓸 게 없으면 아무것도 쓰지 않는다.
